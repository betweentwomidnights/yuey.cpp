New instrumental style

Use WAV/FLAC recordings and matching TXT captions with style, BPM and key. For example: “glitch hop, intricate breakbeat, 88 bpm, D minor”. BPM and key go into the score; style text and your trigger become the training caption. Holdouts are whole recordings.

Advanced recipe

Defaults follow the full-data Koan experiment. 30-second windows fit our 8 GB laptop; 60-second AR training spilled into shared memory and was much slower.

Scored training, v9 semantic labels, posterior-mean audio targets, recording-balanced sampling and the frozen instrumental companion are pinned by the installed runtime. Planning uses the base/common model. Neutral replay is not automatically generated in this workflow. The full Koan run also used generated replay/retention controls; this first UI recipe needs wider musical validation. Python handles dataset orchestration; all model computation, including VAE encoding, uses native GGML on the configured backend; the full experiment was validated with 64 GB of host RAM.

Preparation reserves the local device and unloads inference models. Review coverage and captions before starting optimization.
